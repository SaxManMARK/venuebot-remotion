# VenueBot Remotion Video

This project contains the Remotion build for the VenueBot explainer video.

## Sections

1. Intro
2. Studio AI
3. Convert
4. Care

The first implemented composition is `VenueBotIntro`, built from the existing `M1-SA` and `M1-SB` voiceovers.

## Local setup

```bash
npm install
npm run studio
```

Useful checks:

```bash
npm run still:intro
npm run render:intro
```

## Visual Direction

The video uses VenueBot's brand palette as the base, stretched into a warmer premium presentation style: Agave, Smoky Plum, Porcelain White, cocoa, bronze, and soft cream. The goal is premium product-launch energy with calm pacing, cinematic stat reveals, floating UI-style cards, soft lighting, depth, and refined transitions.
